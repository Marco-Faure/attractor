    Write a model

    One or two equations, in continuous or discrete time. Parameters become sliders.

      How to write a model

      title: Solow with a floor
k' = s*k^alpha - (n + delta)*k
param s = 0.25 [0, 1] Saving rate
param alpha = 0.33 [0.05, 0.95]
param n = 0.01 [0, 0.1]
param delta = 0.05 [0, 0.2]
window k [0, 25]

      Lines you can use

      x' = …
      Continuous time, dx/dt
      x(t+1) = …
      Discrete time, next period's value
      param a = 1 [0, 2] Label
      A slider, its range and its name
      let y = …
      A helper used in the equations
      window x [0, 10]
      Visible range of a variable
      jump c
      A variable free to jump after a shock (saddle-path models)
      init x = 1, y = 2
      First path drawn on load
      horizon 100
      Length of simulated paths
      curve Label: …
      Extra curve on one-variable diagrams
      report Label: …
      Value computed at the steady state
      label x: text
      Axis label

      Expressions

      + - * / ^, parentheses, exp log sqrt abs min max tanh atan sin cos, and the constants pi and e. Greek names such as alpha or rho display as symbols; s_k becomes s with subscript k, istar becomes i*.
